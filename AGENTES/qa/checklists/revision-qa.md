# Checklist de revisión QA

## Comandos

- [ ] `npm run check` ejecutado.
- [ ] `npm test` ejecutado.
- [ ] `npm run build` ejecutado.
- [ ] Comandos y resultados registrados.

## Formularios

- [ ] Campos obligatorios probados.
- [ ] Campos inválidos probados.
- [ ] Campos límite probados.
- [ ] Teléfonos colombianos probados.
- [ ] Correos probados.
- [ ] Fechas probadas.
- [ ] Número de pasajeros probado.
- [ ] Consentimiento probado.
- [ ] Turnstile probado.
- [ ] Rate limiting probado.
- [ ] Doble envío probado.
- [ ] Error de correo probado.
- [ ] Versión de política comprobada.
- [ ] Datos personales ausentes de logs.

## Navegación

- [ ] Enlaces internos revisados.
- [ ] Enlaces externos revisados.
- [ ] Rutas principales revisadas.
- [ ] Errores de consola revisados.

## Accesibilidad

- [ ] Navegación por teclado probada.
- [ ] Foco visible probado.
- [ ] Encabezados revisados.
- [ ] Imágenes revisadas.
- [ ] Errores de formulario asociados correctamente.

## Informe

- [ ] Defectos documentados.
- [ ] Pruebas omitidas documentadas.
- [ ] Fallos de entorno separados de fallos del producto.
- [ ] Handoff completo.
- [ ] Recomendación registrada.
