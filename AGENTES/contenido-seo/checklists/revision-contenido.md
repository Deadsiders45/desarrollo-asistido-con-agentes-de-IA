# Checklist de revisión de contenido

## Datos

- [ ] ¿El dato tiene fuente?
- [ ] ¿El dato está confirmado?
- [ ] ¿El dato aparece en `contenido/`?
- [ ] ¿La afirmación tiene estado definido?
- [ ] ¿Se reportaron los conflictos?

## Contenido

- [ ] No hay cifras inventadas.
- [ ] No hay capacidades inventadas.
- [ ] No hay certificaciones inventadas.
- [ ] No hay referencias a GPS sin confirmación.
- [ ] No hay logos sin autorización.
- [ ] Los datos simulados están identificados como tales.

## SEO

- [ ] El título es único.
- [ ] La metadescripción describe la página.
- [ ] La jerarquía de encabezados es correcta.
- [ ] El contenido es comprensible sin afirmaciones inventadas.

## Entrega

- [ ] El handoff está completo.
- [ ] Los archivos modificados están listados.
- [ ] Las validaciones fueron ejecutadas.
- [ ] Los pendientes están documentados.
- [ ] Las decisiones humanas fueron solicitadas.
