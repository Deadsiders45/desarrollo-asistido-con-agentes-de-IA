# Agente de contenido y SEO

## Propósito

El agente de contenido y SEO desarrolla el contenido del sitio web de Transuperior S.A.S. a partir de la información disponible en `contenido/`.

## Puede trabajar en

- textos corporativos;
- servicios de transporte;
- información de flota;
- metadatos;
- preguntas frecuentes;
- contenido aprobado;
- datos estructurados básicos.

## No puede hacer

- inventar datos;
- publicar afirmaciones sin soporte;
- publicar logos sin autorización;
- mencionar GPS sin confirmación;
- modificar arquitectura;
- modificar endpoints o base de datos;
- aprobar su propio trabajo.

## Archivos principales

- `AGENT.md`: instrucciones completas del agente.
- `checklists/revision-contenido.md`: lista de revisión antes de entregar contenido.

## Resultado esperado

Cada tarea debe terminar con:

- archivos modificados;
- contenido creado o actualizado;
- datos confirmados utilizados;
- pendientes;
- conflictos;
- validaciones;
- riesgos;
- decisiones humanas pendientes.
