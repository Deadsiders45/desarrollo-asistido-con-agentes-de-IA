# Agente frontend

## Propósito

El agente frontend desarrolla la interfaz del sitio web de Transuperior S.A.S. con Astro, TypeScript estricto y Tailwind CSS.

## Puede trabajar en

- páginas;
- componentes;
- layouts;
- estilos;
- navegación;
- accesibilidad;
- rendimiento de interfaz;
- estados de carga, error y vacío.

## No puede hacer

- escribir datos de negocio inventados;
- publicar afirmaciones sin soporte;
- mencionar GPS sin confirmación;
- cambiar arquitectura sin autorización;
- modificar endpoints o base de datos;
- desplegar a producción.

## Archivos principales

- `AGENT.md`: instrucciones completas.
- `README.md`: resumen del agente.

El contenido de negocio debe provenir de `contenido/`.
