# Agente de endpoints y datos

## Propósito

El agente de endpoints y datos desarrolla la capa de servidor del sitio de Transuperior S.A.S.

Trabaja con:

- Cloudflare Pages Functions;
- contratos de validación;
- Neon PostgreSQL;
- migraciones;
- Resend;
- Cloudflare Turnstile;
- rate limiting;
- formularios de cotización y afiliación.

## Puede trabajar en

- endpoints;
- contratos;
- migraciones;
- scripts de exportación;
- pruebas de integración;
- controles de seguridad;
- integración de correo.

## No puede hacer

- registrar datos personales en logs;
- exponer secretos;
- eliminar datos;
- ejecutar migraciones destructivas sin autorización;
- cambiar proveedores;
- modificar producción;
- solicitar documentos innecesarios;
- aprobar su propio trabajo.

## Archivos principales

- `AGENT.md`: instrucciones completas.
- `README.md`: resumen del agente.
- `checklists/revision-endpoints.md`: revisión de seguridad y privacidad.

Las skills son guías. El agente no debe aplicar automáticamente patrones específicos de otros proveedores.
