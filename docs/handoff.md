# Formato de handoff entre agentes

## Handoff de tarea

```markdown
## Handoff

- Tarea:
- Estado:
- Responsable:
- Revisado por:

### Objetivo

### Archivos modificados

### Cambios realizados

### Archivos no modificados

### Pruebas ejecutadas

### Resultados

### Dependencias

### Pendientes

### Riesgos

### Decisiones que requieren aprobación

### Siguiente paso
```

## Reglas

- no marcar una tarea como aprobada sin revisión independiente;
- no ocultar pruebas omitidas;
- no declarar datos simulados como confirmados;
- separar pendientes técnicos de pendientes humanos;
- registrar cualquier conflicto de información;
- enlazar documentos relevantes cuando existan.
