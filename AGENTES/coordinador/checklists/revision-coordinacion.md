# Checklist de coordinación

## Tarea

- [ ] El objetivo está definido.
- [ ] El responsable está asignado.
- [ ] Las dependencias están comprobadas.
- [ ] Los criterios de finalización son verificables.
- [ ] La tarea no amplía el MVP sin autorización.

## Agentes

- [ ] No hay dos agentes modificando los mismos archivos.
- [ ] El agente responsable conoce sus límites.
- [ ] El agente revisor es distinto del implementador.
- [ ] La persona responsable está informada cuando aplica.

## Handoff

- [ ] El handoff está completo.
- [ ] Los archivos modificados están documentados.
- [ ] Las pruebas están documentadas.
- [ ] Los riesgos están documentados.
- [ ] Los pendientes están documentados.

## Cierre

- [ ] Las pruebas pasan.
- [ ] No hay afirmaciones sin soporte.
- [ ] No hay datos inventados.
- [ ] No hay secretos expuestos.
- [ ] No hay datos personales en logs.
- [ ] La decisión está registrada.
- [ ] La tarea tiene estado final.
