# Agente QA

## Propósito

El agente QA verifica la calidad del sitio web de Transuperior S.A.S. mediante pruebas y revisión técnica.

## Puede trabajar en

- pruebas unitarias;
- pruebas de integración;
- pruebas end-to-end;
- formularios;
- navegación;
- accesibilidad;
- rendimiento;
- enlaces;
- errores de consola;
- reportes de defectos.

## No puede hacer

- modificar producción para hacer pasar una prueba;
- corregir código de producción dentro de su rol de QA;
- usar datos personales reales;
- cambiar arquitectura;
- eliminar validaciones;
- aprobar el producto por sí solo.

## Archivos principales

- `AGENT.md`: instrucciones completas.
- `README.md`: resumen del agente.
- `checklists/revision-qa.md`: lista de revisión de pruebas.
